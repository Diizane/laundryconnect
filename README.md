# LaundryConnect

LaundryConnect is a unified knowledge platform for commercial laundry service technicians.

It is designed to help technicians quickly access the information needed to:

- Install equipment
- Operate machines
- Perform maintenance
- Diagnose faults
- Complete repairs
- Find parts and exploded diagrams
- Access wiring diagrams
- Review technical bulletins

## Planned architecture

- Flutter mobile application
- FastAPI backend
- React administration portal
- PostgreSQL database
- Provider-specific document connectors
- Unified search and knowledge layer

## Project status

Initial planning and foundation.
