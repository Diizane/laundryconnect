# LaundryConnect MVP

## Initial capabilities

- Universal search by model, serial number, part number or keyword
- Search across configured provider connectors
- Unified result list
- Results grouped by technical category
- Machine workspace
- In-app PDF viewing
- PDF text search
- Recent searches
- Favourite machines
- Secure backend credential storage
- Connector health monitoring

## Information categories

- Installation
- Operation
- Maintenance
- Diagnostics
- Repair
- Parts and exploded diagrams
- Wiring and electrical
- Programming
- Technical bulletins

## Not included in the first release

- Automated diagnosis
- Parts ordering
- Inventory management
- Full technician account management
- AI-generated repair instructions without source citations
